## Projects

### Ralph-node | Personal Project

**AI Development Pipeline** | April 2026

Built a fully custom, orchestrated AI development pipeline for Node.js from the ground up — no frameworks, no third-party dependencies. The project explores a single thesis: frontier models like Opus 4.7 can be used *efficiently* by routing tasks to the right model for the job, delivering production-quality output at a fraction of the cost.

* **Multi-Model Orchestration:** Designed a routing layer that distributes work across 5 models from 4 providers — Opus 4.7 for planning, DeepSeek V4 Pro for test generation, MiniMax M2.7 for implementation, Opus 4.6 for supervision, and Gemma 4 (local) for summaries.
* **Test-Gated Pipeline:** Every phase is gated behind a test suite and reviewed through automated PR gates. Test generation acts as TDD backpressure — tests are written before implementation, forcing the pipeline to define correct behavior upfront rather than retrofit it.
* **Ralph Loop:** Implementation runs as a tight feedback loop: generate, test, fail, revise — cycling until the suite passes before surfacing output for review.
* **Prompt Architecture:** Engineered role-specific prompts tuned to each model's strengths and cost profile, demonstrating that economics and quality are not mutually exclusive when building AI-native development workflows.

> **Tech Stack:** *Claude, OpenCode, LM Studio, Bash, JavaScript, TypeScript, React, Jest, Playwright, Biome, GitHub Actions*
