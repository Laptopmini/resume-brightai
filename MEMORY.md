Fixed `src/lib/motion.ts` by removing `import type { Variants } from 'framer-motion'` and changing explicit `: Variants` type annotations to `as const` assertions. The `Variants` type from framer-motion v12 has a `Variant` type whose properties don't include `duration` or `type` — those belong on `transition`. Using `as const` lets TypeScript infer the correct shape without the restrictive Variants type.
