## Implementation Plan: Resume Brightai

### Assumptions
- Target deployment is GitHub Pages, served from `https://laptopmini.github.io/resume-brightai/`. The Vite `base` is therefore `/resume-brightai/`.
- The site is a single-page React app (no router, no SSR). One scrollable page with anchor sections.
- Source data lives in `resume.md` and the profile image at `profile.png`. We transcribe the markdown content into a strongly-typed TypeScript content module rather than parsing markdown at runtime; the JUNIOR re-types each section verbatim from `resume.md`.
- No Next.js. We use Vite + React 19 + TypeScript. Tailwind v3 (not v4) for styling.
- Existing repo placeholder (`src/index.ts`) is unused and may stay; new code lives under `src/` alongside it.
- Jest is reused for component-level unit tests with a `jsdom` environment; Playwright config is left as-is.
- Node 24 / npm 11 per `engines`. The deploy workflow uses Node 24.
- Protected files (`.github/scripts/**`, `.github/prompts/**`, `.claude/settings.json`, `.aignore`, `biome.json`) are not modified.

### Design Intent

The site mirrors bright.ai: a dark midnight canvas, white sans-serif type, and electric gradient accents on buttons / dividers / hero punctuation. We commit the following tokens; downstream tickets import them by name.

**Color tokens** (defined as CSS variables in `src/styles/globals.css` and mirrored into `tailwind.config.ts` under `theme.extend.colors`):
- `--midnight: #0a0e2c` → `bg-midnight` (page background)
- `--midnight-deep: #050720` → `bg-midnight-deep` (section bands, footer)
- `--midnight-card: #11154a` → `bg-midnight-card` (cards / experience tiles)
- `--paper: #f4f5fb` → `text-paper` (body copy on dark)
- `--paper-muted: #a4abd1` → `text-paper-muted` (secondary copy, dates)
- `--ink: #10112d` → `text-ink` (text color used on `bg-gradient-accent` stack pills in ExperienceCard and ProjectCard)
- `--cyan-blue: #0693e3` → `text-cyan-blue` (eyebrows, accents, hover)

Note: `#9b51e0` (vivid purple), `#2874fc` (electric mid), and `#020381` (electric deep) are NOT exposed as standalone Tailwind colors. They live exclusively as gradient stops inside `--gradient-midnight` and `--gradient-accent` — components reference those gradients via `bg-gradient-midnight` / `bg-gradient-accent`, never the raw stops.

**Gradient tokens** (defined as CSS variables and exposed as Tailwind `backgroundImage` keys):
- `--gradient-midnight: linear-gradient(135deg, #020381 0%, #2874fc 100%)` → `bg-gradient-midnight` (used by primary CTA button, "Want to know more?" banner)
- `--gradient-accent: linear-gradient(135deg, #0693e3 0%, #9b51e0 100%)` → `bg-gradient-accent` (used by SectionDivider, hero name underline, secondary buttons)
- `--gradient-spectrum: linear-gradient(135deg, #4aeadc 0%, #9778d1 20%, #cf2aba 40%, #ee2c82 60%, #fb6962 80%, #fef84c 100%)` → `bg-gradient-spectrum` (used by AICreditSection top border strip)

**Typography** (font stack registered in `tailwind.config.ts` `theme.extend.fontFamily.sans`, loaded via `index.html` Google Fonts link in Ticket 4):
- Display + body: `'Inter', 'Helvetica Neue', Helvetica, Arial, sans-serif`
- Weights used: 300 (body), 500 (UI), 700 (headings), 800 (hero title)
- Hero title: `text-5xl md:text-7xl font-extrabold tracking-tight`
- Section title: `text-3xl md:text-4xl font-bold`
- Body: `text-base font-light leading-relaxed`

**Layout rhythm**:
- Page wrapper `max-w-content mx-auto px-6` (Tailwind `maxWidth.content = '1100px'`; consumed by App's section containers)
- Section vertical rhythm `py-24 md:py-32` — every section wrapper uses this exact pair of classes
- Sections separated by `<SectionDivider />` (a 1px gradient bar using `bg-gradient-accent`)
- Card radius `rounded-2xl`, card border `border border-white/5`

**Motion presets** (named exports from `src/lib/motion.ts`, consumed by component tasks via `import { heroReveal, cardHover, navStick, gradientShimmer } from "@/lib/motion"`):
- `heroReveal`: `{ initial: { opacity: 0, y: 24 }, animate: { opacity: 1, y: 0 }, transition: { duration: 0.7, ease: [0.16, 1, 0.3, 1] } }`

- `navStick`: `{ initial: { y: -64 }, animate: { y: 0 }, transition: { type: "spring", stiffness: 220, damping: 26 } }`
- `gradientShimmer`: `{ animate: { backgroundPosition: ["0% 50%", "100% 50%", "0% 50%"] }, transition: { duration: 8, repeat: Infinity, ease: "linear" } }`

**Copy voice** (exported strings under stable keys in `src/content/resume.ts`; components must import by key, never re-type):
- `hero.eyebrow`: `"Senior Software Developer"`
- `hero.title`: `"Paul-Valentin Mini"`

### 1. Tech Stack & Architecture Notes
**Detected stack:** TypeScript (strict), Jest 30 with @swc/jest (currently `node` env, needs `jsdom` for components), Playwright 1.58, Biome 2.4 formatter, Node 24+. Empty `src/index.ts` placeholder. No frontend framework yet.
**Relevant existing patterns:** Tests live under `tests/unit/*.test.{ts,tsx}` (already supported by `testMatch`). Biome enforces double-quote, trailing commas, 100-col line width. The repo has a Maestro automation pipeline driving CI prompts.
**Recommendations:** Use Vite 6 + `@vitejs/plugin-react` for the React SPA — small toolchain, native GitHub Pages SPA support via `base`. Use Tailwind v3.4 (NOT v4 — v4 PostCSS plugin churn is a known footgun). Pin `framer-motion` for the documented motion presets. All asset URLs go through a `withBasePath` helper (`src/lib/basePath.ts`) using Vite's `import.meta.env.BASE_URL`. Add a `types/css.d.ts` ambient module for `*.css` and `*.png` imports so `tsc --noEmit` passes. Update `jest.config.mjs` to use `jest-environment-jsdom` and stub CSS imports via `moduleNameMapper`.
